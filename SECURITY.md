# Security policy

## Supported versions

Production is the `main` branch deployed at [https://evenly.lapardhaja.com](https://evenly.lapardhaja.com).

## Reporting a vulnerability

Email **servetlap29@gmail.com**. Do not open a public GitHub issue for unreleased vulnerabilities.

Include:

- The URL or API path (`POST /api/scan`, `POST /api/chat-push`, a hash route, etc.)
- A clear description and steps to reproduce
- Impact (for example: read another user’s receipts without membership)

Please stay within this product. Do not access other people’s data beyond what is needed to demonstrate the issue.

Machine-readable contact: [/.well-known/security.txt](https://evenly.lapardhaja.com/.well-known/security.txt). In-app summary: [Security](https://evenly.lapardhaja.com/#/security).
